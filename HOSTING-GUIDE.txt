راهنمای نصب Coach Master به‌صورت آیکون روی گوشی (رایگان، با GitHub Pages)
==========================================================================

چرا؟ گوشی‌ها فقط برنامه‌ای را که از یک آدرس https باز شده، به‌صورت آیکون نصب می‌کنند.
بعد از اولین باز شدن، برنامه بدون اینترنت هم کار می‌کند و داده‌ها فقط روی همان گوشی می‌مانند.

یک بار انجام دهید:
1) در github.com یک حساب رایگان بسازید.
2) New repository ← نام: coachmaster ← Public ← Create.
3) Add file ← Upload files ← دو پوشه coach-web و player-web را (خود پوشه‌ها را) آپلود کنید ← Commit.
4) Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root) ← Save.
5) بعد از ۱ تا ۲ دقیقه آدرس‌ها آماده است:
   مربی:   https://<نام-کاربری>.github.io/coachmaster/coach-web/
   بازیکن: https://<نام-کاربری>.github.io/coachmaster/player-web/

بعد از آن:
- آدرس بازیکن را در برنامه مربی، تب «داده‌ها»، قسمت «آدرس اینترنتی برنامه بازیکن» وارد کنید تا QR دعوت مستقیم برنامه را باز کند.
- مربی: قبل از رفتن به نسخه اینترنتی، در فایل فعلی «پشتیبان» بگیرید و در نسخه جدید «بازیابی» کنید.
- نصب در اندروید: Chrome ← منوی سه‌نقطه ← Install app یا Add to Home screen
- نصب در آیفون: Safari ← دکمه اشتراک ← Add to Home Screen
- به‌روزرسانی: فایل‌های جدید را روی همان پوشه‌ها آپلود کنید؛ داده‌ها پاک نمی‌شوند (آدرس را عوض نکنید).

هر هاست دیگری با https (مثلاً Netlify Drop یا هاست داخلی) هم همین‌طور کار می‌کند.
